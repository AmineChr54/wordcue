    How a film gets made.

    1. Brief You describe it. Claude writes down the audience, the takeaway and the allowed facts.
    2. Story Claude writes the script. If the angle is unclear, rival outlines compete.
    3. Look A new look, clearly different from your earlier projects.
    4. Voice Each line is recorded several times. Speech recognition keeps the closest take, and the build stops if none matches.
    5. Build The animation hangs on word times, so a title can land on its word.
    6. Review An independent reviewer checks facts and frames, for up to two rounds.
    7. Render One page becomes an MP4 and an interactive player. Only you can judge the sound, so you listen last.

    Try it.

    You need Windows, Git Bash, uv, ffmpeg, Node.js, Microsoft Edge and Claude Code.

    git clone https://github.com/AmineChr54/wordcue
cd wordcue
bash setup.sh
bash claude/sync.sh install
cp used-looks.example.md used-looks.md

    Then open Claude Code and describe your film. The README has the full workflow.
