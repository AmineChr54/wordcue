# Recipe: tech-explorer

**Status: not yet run through this kit, and the film engine doesn't cover free exploration.**

Someone explores a system at their own pace: pan, zoom, drill down. There's no fixed timeline, so build a plain interactive page and use the film engine only for embedded guided tours.

- **Stages:** brief, art rivals only if there's no look, build, one review round focused on accuracy.
- **Form carries meaning:** colour means protocol, a dashed line means planned, size means load. Include a legend, and use each encoding for one thing only.
- **Structure:** SVG diagram, pan and zoom, drill-down into a component, then a guided sequence that plays a real flow step by step.
- **Motion is data:** if something moves, it's because a message or request really goes that way.
- **Accuracy matters most here.** The fact-check traces every component and connection to the source.
